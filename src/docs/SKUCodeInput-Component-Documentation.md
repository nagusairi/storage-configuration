# SKUCodeInput Component Documentation

## 📋 Overview

**Component Name:** `SKUCodeInput`  
**File Location:** `/components/ui/SKUCodeInput.tsx`  
**Category:** Form Input Component (Advanced)  
**Version:** 1.0.0

The **SKUCodeInput** component is a sophisticated, enterprise-grade input field designed specifically for Stock Keeping Unit (SKU) code management in inventory systems. It provides dual operation modes with intelligent autocomplete, duplicate detection, and AI-powered suggestions.

---

## 🎯 Key Features

### Core Functionality
1. **Dual Mode Operation**
   - Auto Generate: System-generated SKU codes with copy functionality
   - Manual Entry: User input with intelligent autocomplete

2. **Intelligent Autocomplete**
   - AI-driven suggestions based on patterns
   - System-defined suggestions
   - Real-time filtering as you type
   - Text highlighting for matched characters

3. **Keyboard Navigation**
   - Arrow Up/Down: Navigate suggestions
   - Enter: Select highlighted suggestion
   - Escape: Close dropdown

4. **Duplicate Detection**
   - Real-time duplicate SKU validation
   - Visual error indicators
   - Smart alternative suggestions

5. **AI-Powered Smart Suggestions**
   - Pattern-based suggestions
   - Sequential numbering detection
   - Confidence scores
   - One-click application

6. **Copy to Clipboard**
   - One-click copy for auto-generated SKUs
   - Visual feedback on successful copy

## 🔧 Props Interface

### Core Props

| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| `mode` | `'auto' \| 'manual'` | ✅ Yes | - | Current operation mode |

| `autoGeneratedValue` | `string` | ❌ No | `''` | Auto-generated SKU (auto mode) |
| `onModeChange` | `(mode: 'auto' \| 'manual') => void` | ✅ Yes | - | Mode change handler |
| `onChange` | `(value: string) => void` | ✅ Yes | - | Value change handler |

### Suggestions Props

| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| `suggestions` | `SKUSuggestion[]` | ❌ No | `[]` | Array of autocomplete suggestions |
| `onSuggestionSelect` | `(value: string) => void` | ❌ No | - | Callback when suggestion is selected |

### Duplicate Detection Props

| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| `isDuplicate` | `boolean` | ❌ No | `false` | Whether current SKU is duplicate |

### Complete Example with All Features

```tsx
import { useState, useEffect } from 'react';
import { SKUCodeInput, SKUSuggestion } from '../../components/ui/SKUCodeInput';

function AdvancedProductForm() {
  const [skuMode, setSkuMode] = useState<'auto' | 'manual'>('manual');
  const [skuValue, setSkuValue] = useState('');
  const [autoSKU, setAutoSKU] = useState('');
  const [isDuplicate, setIsDuplicate] = useState(false);

  // Mock existing SKUs database
  const existingSKUs = ['SKU-001', 'SKU-002', 'SKU-003'];

  // Generate auto SKU when mode changes to auto
  useEffect(() => {
    if (skuMode === 'auto') {
      const timestamp = Date.now();
      setAutoSKU(`SKU-AUTO-${timestamp}`);
    }
  }, [skuMode]);

  // Check for duplicates
  useEffect(() => {
    if (skuMode === 'manual' && skuValue) {
      setIsDuplicate(existingSKUs.includes(skuValue));
    } else {
      setIsDuplicate(false);
    }
  }, [skuValue, skuMode]);

  // Generate suggestions based on user input
  const suggestions: SKUSuggestion[] = [
    { value: 'SKU-ELEC-2024-001', type: 'ai', reason: 'Based on category' },
    { value: 'SKU-ELEC-2024-002', type: 'ai', reason: 'Sequential pattern' },
    { value: 'SKU-FURN-2024-001', type: 'match', reason: 'Similar items' },
    { value: 'SKU-GADGET-001', type: 'match', reason: 'Recent entries' }
  ];

  // Custom duplicate suggestions
  const duplicateSuggestions = {
    aiSuggestion: `${skuValue}-V2`,
    patternSuggestion: skuValue.match(/^(.+?)[-_]?(\d+)$/) 
      ? skuValue.replace(/(\d+)$/, (match) => String(parseInt(match) + 1).padStart(3, '0'))
      : `${skuValue}-002`,
    aiConfidence: 95,
    patternConfidence: 92
  };

  return (
    <div className="max-w-2xl">
      <SKUCodeInput
        mode={skuMode}
        value={skuValue}
        autoGeneratedValue={autoSKU}
        onModeChange={setSkuMode}
        onChange={setSkuValue}
        suggestions={suggestions}
        onSuggestionSelect={(value) => {
          console.log('User selected SKU:', value);
          // Track selection analytics
        }}
        isDuplicate={isDuplicate}
        duplicateSuggestions={duplicateSuggestions}
        required
        label="Product SKU Code"
        autoModeLabel="Auto Generate SKU"
        manualModeLabel="Manual SKU Entry"
      />
    </div>
  );
}
```

## 🎯 Interaction Patterns

### 1. Mode Switching
```tsx
// User clicks "Auto Generate" radio
onModeChange('auto')
→ Input becomes disabled
→ Shows auto-generated SKU
→ Copy button appears
→ Suggestions dropdown closes

// User clicks "Manual Entry" radio
onModeChange('manual')
→ Input becomes enabled
→ Clears auto-generated value
→ Shows manual placeholder
→ Can type and see suggestions
```

### 2. Autocomplete Flow
```tsx
// User types in manual mode
onChange('SKU-E')
→ Filters suggestions containing 'SKU-E'
→ Shows dropdown with AI and System suggestions
→ Highlights first suggestion
→ User can navigate with arrows
→ Press Enter to select
```

### 3. Duplicate Detection Flow
```tsx
// User enters duplicate SKU
onChange('SKU-001')
→ isDuplicate becomes true
→ Shows error banner in dropdown
→ Shows warning panel below input
→ Displays 2 smart suggestions (AI + Pattern)
→ User can click "Use this" to apply suggestion
```

### 4. Copy Functionality (Auto Mode)
```tsx
// User clicks copy button
handleCopy()
→ Copies SKU to clipboard
→ Button shows "Copied!" tooltip
→ Button background turns green briefly
→ Returns to normal after 1.5s
```

## 🚀 Best Practices

### 1. Always Provide Suggestions in Manual Mode
```tsx

  mode="manual"
  value={sku}
  suggestions={generateSuggestions(sku)}
  // ...
/>

// ❌ BAD
<SKUCodeInput
  mode="manual"
  value={sku}
  // No suggestions provided
  // ...
/>
```

### 2. Implement Duplicate Checking
```tsx
// ✅ GOOD
useEffect(() => {
  const isDupe = existingSKUs.includes(skuValue);
  setIsDuplicate(isDupe);
}, [skuValue, existingSKUs]);

<SKUCodeInput isDuplicate={isDuplicate} {...props} />
```

### 3. Generate Auto SKU on Mode Change
```tsx
// ✅ GOOD

  if (mode === 'auto') {
```

### 4. Track User Selections for Analytics
```tsx
// ✅ GOOD

  // ...
```

## 🐛 Common Issues & Solutions

### Issue 1: Dropdown Not Showing
**Cause:** `showSuggestions` state not managed properly  
**Solution:** Ensure suggestions array has items and mode is 'manual'

### Issue 2: Copy Button Not Working
**Cause:** Browser security restrictions  
**Solution:** Component uses fallback method with `execCommand` for compatibility

### Issue 3: Keyboard Navigation Not Working
**Cause:** Input not focused or suggestions not visible  
**Solution:** Ensure dropdown is open and `filteredSuggestions.length > 0`

## 📊 Performance Considerations

- **Debounce Search:** For large suggestion lists, debounce the `onChange` handler
- **Memoize Suggestions:** Use `useMemo` to avoid recalculating suggestions on every render
- **Lazy Load:** Load suggestions asynchronously if fetching from API

```tsx
// Example: Debounced search
const debouncedSearch = useMemo(
  () => debounce((value: string) => {
    fetchSuggestions(value).then(setSuggestions);
  }, 300),
  []
);

<SKUCodeInput
  onChange={(value) => {
    setValue(value);
    debouncedSearch(value);
  }}
  // ...
/>
```
