# GST Test Numbers for Vendor Auto-Fill

This document contains all available GST numbers for testing the AI-assisted vendor prefill functionality in the "Add Vendor" flow.

## How to Use

1. Click "Add Vendor" button
2. In the GST Pre-Fill section (Step 0), enter any of the GST numbers below
3. Click "Prefill the Data" button
4. The system will auto-fill vendor information across all steps
5. Fields filled by AI will show:
   - Purple left border
   - Small "AI" badge at top-left
   - All data remains editable

## Notes

- All GST numbers are **15 characters** in alphanumeric format
- First 2 digits represent the **state code**
- Auto-filled data includes **10 fields** across Steps 1 and 4:
  - Top Vendor Details
  - Business Legal Entity
  - Legal Name
  - Company Name
  - Trade Name
  - Address Line 1
  - Address Line 2
  - City
  - State
  - Pincode
- User can **edit any auto-filled field** before proceeding
- Invalid GST numbers will show: "GST number not found in database. Please enter details manually."

## Adding More Test Data

To add more GST test numbers, update the `mockGSTData` object in `/components/ProductDetailsTabContent_VendorsTab_DataGrid.tsx`:

```typescript
const mockGSTData: Record<string, any> = {
  'YOUR_GST_NUMBER': {
    legalName: 'Full Legal Business Name',
    companyName: 'Short Company Name',
    tradeName: 'Trade/Brand Name',
    addressLine1: 'Street Address',
    addressLine2: 'Additional Address Info',
    city: 'City Name',
    state: 'State Name',
    pincode: '123456',
    businessLegalEntity: 'Company|LLP|Partnership|Individual',
    topVendorDetails: 'Registered Business - Regular|Composition'
  }
};
```
