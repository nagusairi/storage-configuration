## 🐛 Troubleshooting Guide

### Issue: Dropdown not showing
**Solution:** Ensure `mode="manual"` and `suggestions` array has items

### Issue: Copy button not visible
**Solution:** Set `mode="auto"` and provide `autoGeneratedValue`

### Issue: Keyboard navigation not working
**Solution:** Ensure dropdown is open and focused

### Issue: Duplicate warning not appearing
**Solution:** Set `isDuplicate={true}`

### Issue: Suggestions not filtering
**Solution:** Component auto-filters based on `value` prop

## 📈 Performance Tips

1. **Debounce Search**
   ```tsx
   const debouncedSearch = useMemo(
     () => debounce(fetchSuggestions, 300),
     []
   );
   ```

2. **Memoize Suggestions**
   ```tsx
   const suggestions = useMemo(
     () => generateSuggestions(sku),
     [sku]
   );
   ```

3. **Lazy Load**
   ```tsx
   const [suggestions, setSuggestions] = useState([]);
   useEffect(() => {
     if (sku.length > 2) {
       fetchSuggestions(sku).then(setSuggestions);
     }
   }, [sku]);
   ```
