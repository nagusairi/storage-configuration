# SKUCodeInput - Quick Reference Guide

## 🚀 Quick Start (30 seconds)

```tsx
import { useState } from 'react';
import { SKUCodeInput } from '../../components/ui/SKUCodeInput';

function MyForm() {
  const [mode, setMode] = useState<'auto' | 'manual'>('manual');
  const [sku, setSKU] = useState('');

  return (
    <SKUCodeInput
      mode={mode}
      value={sku}
      onModeChange={setMode}
      onChange={setSKU}
    />
  );
}
```

---

## 📋 Must-Have Props

| Prop | Type | What It Does |
|------|------|--------------|
| `mode` | `'auto' \| 'manual'` | Which mode is active |
| `value` | `string` | The SKU value (manual mode) |
| `onModeChange` | `function` | Called when user switches mode |
| `onChange` | `function` | Called when SKU changes |

---

## 🎯 Common Use Cases

### 1. Basic Manual Entry
```tsx
<SKUCodeInput
  mode="manual"
  value={sku}
  onModeChange={setMode}
  onChange={setSKU}
/>
```

### 2. Auto-Generate SKU
```tsx
<SKUCodeInput
  mode="auto"
  value={sku}
  autoGeneratedValue="SKU-AUTO-12345"
  onModeChange={setMode}
  onChange={setSKU}
/>
```

### 3. With Autocomplete
```tsx
<SKUCodeInput
  mode="manual"
  value={sku}
  onModeChange={setMode}
  onChange={setSKU}
  suggestions={[
    { value: 'SKU-001', type: 'ai', reason: 'AI suggestion' },
    { value: 'SKU-002', type: 'match', reason: 'Similar' }
  ]}
/>
```

### 4. Duplicate Detection
```tsx
<SKUCodeInput
  mode="manual"
  value={sku}
  onModeChange={setMode}
  onChange={setSKU}
  isDuplicate={existingSKUs.includes(sku)}
/>
```

## ⚡ Pro Tips

### Tip 1: Generate Auto SKU Dynamically
```tsx
useEffect(() => {
  if (mode === 'auto') {
    setAutoSKU(`SKU-${Date.now()}`);
  }
}, [mode]);
```

### Tip 2: Check Duplicates in Real-Time
```tsx
useEffect(() => {
  setIsDuplicate(existingSKUs.includes(sku));
}, [sku]);
```

### Tip 3: Track Analytics
```tsx
<SKUCodeInput
  onSuggestionSelect={(value) => {
    analytics.track('SKU_SELECTED', { value });
  }}
  // ... other props
/>
```

---

## 🐛 Troubleshooting

| Problem | Solution |
|---------|----------|
| Dropdown not showing | Make sure `mode="manual"` and `suggestions` array has items |
| Copy button missing | Set `mode="auto"` and provide `autoGeneratedValue` |
| Duplicate warning not showing | Set `isDuplicate={true}` |
